# Timothy Nghiem Portfolio

## Goal
Build a polished, single-page personal website portfolio for Timothy (Thang) Nghiem that presents academic rigor, analytical capabilities, international perspective, and selected work for elite Finance, Audit, and Economics roles. Keep the experience unmistakably personal, with Timothy’s name, perspective, credentials, and work as the central focus rather than presenting it like a company or software product.

## Experience
- Create a fixed, understated header with the T. NGHIEM wordmark and smooth in-page navigation.
- Build a warm cinematic opening section with the supplied headline, identity details, and direct links to work samples and transcript.
- Present About, Academic, Capabilities, Selected Work, Perspectives, Author Note, and Contact as spacious editorial sections in the requested order.
- Add a custom interactive world map highlighting France, China, Denmark, Germany, UAE, Qatar, and Finland, with accessible country labels and subtle hover/focus details.
- Use compact custom analytical line icons for the five capability areas.
- Make all external links, email, and phone actions functional and clearly styled.

## Visual Direction
- Warm cream canvas, charcoal typography, espresso structure, and muted copper highlights.
- Editorial serif display type paired with a restrained sans-serif body face.
- Structured grids, fine rules, translucent panels, and modest corner radii.
- A generated cinematic still-life image referencing financial research, maps, and archival documents without inventing Timothy’s likeness.
- Subtle entrance and map-marker motion, with reduced-motion support.

## Technical Details
- Implement the experience at `/` using the existing TanStack route structure.
- Define all palette, typography, shadow, and motion values as semantic tokens in the global design system.
- Use a lightweight inline SVG world map with interactive markers; no external map service or persistent data is required.
- Add page-specific title, description, Open Graph, and Twitter metadata.
- Verify rendering and interactions at desktop and mobile widths.
